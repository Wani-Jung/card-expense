## 2. 입력 경로

| 경로 | 어디서 | 조건 | 들어가는 곳 |
|---|---|---|---|
| 문자 실시간 수신 | `SmsReceiver` (RECEIVE_SMS) | '문자 읽기' 앱에서 사용 켜짐 + 본문 카드번호+승인·취소 | 네이티브 inbox → 앱 켤 때 분류 대기 |
| 알림 감지 | `CardNotificationListener` | '알림 감지' 사용 켜짐 + 알림 제목 발신번호 일치 또는 본문 카드번호 | 네이티브 inbox → 분류 대기 |
| 지난 문자 불러오기 | 메뉴 > 결제내역, 사전입력 3단계 (`SmsInbox.readInbox(from, to)`, READ_SMS) | **사용자가 고른 기간만**(빠른 선택 이번 달·최근 3개월·최근 1년, 고른 버튼 남색). SMS·MMS·RCS 후보 저장소, 날짜 칸 없는 저장소는 건너뜀. 미리보기 → [불러오기] | 분류 대기 |
| 붙여넣기 | 메뉴 > 문자 붙여넣기 | 여러 건 쪼개기, 카드번호+승인 | 분류 대기 |
| 공유 | 메시지 앱 → 공유 → 공감카드 관리 | 붙여넣기와 같음 | 분류 대기 |

- **자동 불러오기 없음**: 2.0.3(REQ-69)부터 권한을 허용해도 앱이 스스로 지난 문자를 훑지 않는다. 예전 `auto_import_done` 키는 읽지 않는다.
- 문자 권한 요청은 항상 앱 안 안내(`lib/disclosure.dart`) → [동의하고 계속] → 시스템 권한 창. 거부해도 알림 감지·붙여넣기·공유로 쓸 수 있다.
- 불러오기 진단: 미리보기·결과 팝업 제목을 길게 누르면 '찾은 카드 승인 문자 n건 · 그중 발신번호 일치 n건 · 주소 형식'. 문자함 전체 건수는 어디에도 보여 주지 않는다.
- 캡처(OCR) 입력은 2.0.0(REQ-47)에서 없앴다.

## 3. 화면 (메뉴 순서)
1. 메인: 월 진행 표시줄 + ◀ 제목 ▶ + 요약표(수립·사용·잔여, 단위 원/천원/만원, 보기 1개월·홀짝·짝홀) 고정(보는 기간에 미분류가 있으면 표 대신 파란 분류 안내), 아래 분류 대기 한 줄 카드(보는 기간 것만 + '다른 달 미분류 n건 ›')·확인 필요 줄·내역 스크롤. 차량비 잔여 경고 아이콘·팝업. 권한 배너는 2.1.1 에서 없앰
2. 메뉴(톱니) 7개: 결제내역(지난 문자 불러오기·문자 붙여넣기·미분류·확인 필요·무시한 내역·분류한 내역·미분류 알림 스위치) / 등록 업체·추천 키워드 / 카드 문자 설정 / 권한 설정(문자 읽기 꺼짐이면 노란 !) / 실험실 / 개인정보처리방침 / 버전 정보(스토어판) + 'Made by wani'(문의 팝업 + 오픈소스 라이선스)
3. 실험실: 안전 OX Quiz(매일 퀴즈 스위치 기본 꺼짐·챌린지·한 문제 더·지난 문제·점수 기록 지우기) / 법령 Quiz 4종(농어촌정비법·건설기술 진흥법·국가계약법·건축법, 제목만) + 출처·'정부와 무관·법적 효력 없음' 고지
4. 사전입력사항 3단계(첫 실행에만, 2.1.1 부터 메뉴엔 없음): ① 이번 달 수립 ② 카드번호 끝 4자리·발신번호 ③ 지난 결제 기간 지정 불러오기(권한을 못 받으면 붙여넣기·공유 안내)

## 4. 분류·검사 (요약)
- 추천: 자동 등록 업체 > 직접 키워드 > 기본 키워드(세트 v3). 고르면 같은 가맹점 대기 건 일괄 정리 + 자동 등록, 5초 [되돌리기]
- 확인 필요 규칙: 같은 업체 분류 섞임 / 추천과 반대 / 10분 안 같은 금액 중복 / 승인 후 취소 / 원승인 없는 취소 / 들어올 때 미래·1년 넘은 날짜
- 무시 사유: 직접 무시 / 중복 / 취소로 상쇄. 무시한 내역은 보관, 되살리면 미분류로
- 미분류 내역 맨 위 '이번 달 이전 미분류 n건 한꺼번에 무시'(그런 건이 있을 때만)
- 미분류 알림(유일한 상태바 알림): 이번 달 + (1~15일엔) 지난달 미분류 중 7일 넘은 건, 평일 17~21시, 7일 간격. 문구 3종

## 7. 빌드·배포
- 태그 `v*` push 에서만 CI(`.github/workflows/release-apk.yml`): `flutter test`(+스토어 채널) → APK(스모크용)·스토어 AAB 빌드 → 권한 검사 → Kotlin 단위 테스트 → 업데이트 코드 검사(스토어 AAB 에 GitHub API 주소 없어야 함) → 에뮬레이터 스모크(APK·AAB 30초 생존) → 릴리스(AAB 만, `--latest=false`)
- dev: Actions 수동 실행 → `dev` 프리릴리스(AAB 만)
- 사용자 폰 확인은 내부 테스트 트랙, 정식은 프로덕션(대한민국·전체). AAB 업로드는 사용자가 직접 드래그
